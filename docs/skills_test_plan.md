# اختبار مهارات Copilot

توجد ثلاث مهارات خاصة بالمشروع في `.github/skills/`، بينها `arabic-demand-reporting-project` لإعداد التقارير والعروض العربية. توجد أيضًا نسخة شخصية منفصلة للمستخدمة باسم `arabic-demand-reporting` في `~/.copilot/skills/`؛ هذه النسخة ليست جزءًا من ملفات المشروع ولا تُشارك تلقائيًا مع الفريق. استخدم الطلبات التالية في Copilot Chat بعد فتح مساحة العمل، وراجع اسم المهارة/سجل التعليمات المحمّلة إن كان ظاهرًا في واجهة VS Code.

| الاختبار | الطلب | المهارة المتوقعة | معيار النجاح |
|---|---|---|---|
| إيجابي: استكشاف | «حلّل اتجاه إجمالي الطلب أسبوعيًا وحدد الفئات والوجبات التي تتجاوز 80%، مع فحص تغطية المراكز.» | `weekly-demand-exploration` | الإشارة إلى `train.csv`، عدم ملء الأسبوع المفقود بصفر، وذكر إجمالي الطلب/الأسابيع ومصدر الجدول. |
| سلبي: استكشاف | «اكتب رسالة ترحيب قصيرة لموظف جديد.» | لا مهارة تحليلية | لا تحميل ولا استدعاء لمهارتي استكشاف الطلب أو اختبار الترويج. |
| إيجابي: ترويج | «قارن طلب البريد والصفحة الرئيسية داخل أزواج مركز-وجبة متطابقة، وصحح اختبارات p بطريقة Holm، ثم اقترح تجربة عشوائية.» | `promotion-impact-testing` | الفصل بين الارتباط والسببية، إظهار أحجام العينات والوسيط والفرق واختبار Holm، واقتراح قياس الهامش والحواجز. |
| سلبي: ترويج | «غيّر تنسيق عنوان README إلى Markdown من المستوى الثاني.» | لا مهارة تحليلية | لا تحميل ولا استدعاء لمهارة الترويج أو استكشاف الطلب. |
| إيجابي: تقرير المشروع | «اكتب ملخصًا عربيًا لنتائج تحليل الطلب لمدير غير تقني، واربط الأرقام بخلايا الدفتر واذكر القيود والتوصيات.» | `arabic-demand-reporting-project` | ملخص عربي مبني على نتائج قابلة للتتبع، مع فصل الحقائق عن التفسير والتوصيات وتجنب الادعاء بالسببية. |
| سلبي: تقرير المشروع | «اكتب رسالة تهنئة قصيرة بعيد الميلاد.» | لا مهارة من مهارات تحليل الطلب | لا تحميل لمهارات التقارير أو الطلب؛ فالطلب لا يتعلق بتحليل الطلب أو إعداد تقرير أعمال. |

## تحقق محلي قبل الاستخدام

- لكل ملف `SKILL.md` اسم يطابق مجلده، ووصف يحتوي عبارات استدعاء واضحة، وإجراءات خاصة بالمشروع.
- قاعدة الأوصاف ضيقة: طلب استكشاف أسبوعي لا يطلب حملة/خصم؛ وطلب تنسيق Markdown لا يطلب تحليلًا.
- مهارة `arabic-demand-reporting-project` موجودة في `.github/skills/` ولذلك نطاقها المشروع؛ النسخة الشخصية تبقى منفصلة في ملف تعريف المستخدمة.
- التشغيل التفاعلي للاختبارات الإيجابية والسلبية يتطلب Copilot Chat في VS Code؛ شغّل الطلبات أعلاه يدويًا بعد إعادة فتح مساحة العمل، إذ لا تستطيع هذه الدفترية تنفيذ محادثات Copilot Chat أو التحقق من سجل تحميلها.
